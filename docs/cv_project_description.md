## Option 1: Data Scientist / ML Engineer Resume

- Architected an end-to-end churn prediction and decision intelligence platform on 7,043 authentic enterprise customer records, deploying a calibrated XGBoost pipeline achieving **0.8467 Test ROC-AUC** and **0.1361 Brier score**.

- Engineered a prescriptive retention decision layer stratifying accounts into 4 operational risk tiers, mapping $139K/mo revenue exposure, and simulating campaign ROI with interactive sensitivity modeling.
- Built a modular SQLite analytical data warehouse with 10 custom SQL queries, an interactive Streamlit BI application, and an automated 33-test Pytest validation suite.
